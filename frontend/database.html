MySQL 数据库连接测试

输入账号密码后由后端建立临时连接并返回结果，不会保存任何凭据。
POST http://localhost:8325/api/database/test 请求体：user / password / host / port / database 
{
  "user": "root",
  "password": "123456",
  "host": "127.0.0.1",
  "port": 8430,
  "database": "msyj430_ketangai"
}

连接参数

默认账号 root / 123456，可直接点击“测试连接”。

提示：本地 MySQL 实例端口为 8430，库名 msyj430_ketangai。 如果连接失败，请先运行根目录 start.bat 确认数据库已启动。
